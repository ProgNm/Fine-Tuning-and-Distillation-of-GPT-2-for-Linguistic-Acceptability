Machine Learning Techniques: Text Generation, LoRA, and Knowledge Distillation
This repository contains the implementation and analysis covering three important techniques in modern machine learning and NLP:

Text Generation using GPT-2
Parameter-Efficient Fine-Tuning using LoRA
Knowledge Distillation from a GPT-2 teacher to an RNN student

The project investigates how large language models can be adapted efficiently and how their knowledge can be transferred to smaller models for resource-constrained deployment.


Important Files
model.py — Model definitions and GPT-based language model implementation.
run.py — Main execution/training script.
train_utils.py — Training and evaluation utilities.
utils.py — Supporting utility functions.
tuning/ — Hyperparameter tuning experiments.
